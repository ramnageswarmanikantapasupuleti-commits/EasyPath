# EasyPath — Product Requirements Document (PRD)

***

## 1\. Overview

**App Name:** EasyPath
**Build Type:** Progressive Web App (PWA)

EasyPath is an accessibility-first Progressive Web App designed to empower individuals with cognitive disabilities, learning differences, acquired brain injuries, dementia, autism, or intellectual disabilities to navigate daily life with greater independence and confidence. The application provides an ultra-simplified, deeply personalized interface that breaks down complex tasks into manageable visual steps, delivers intelligent reminders, and leverages AI to translate difficult language and real-world objects into plain, understandable information. EasyPath operates across devices via a PWA architecture, ensuring offline functionality for core features and eliminating installation barriers.

The primary target audience includes adults and young adults with cognitive impairments, alongside a secondary audience of caregivers, family members, teachers, and therapists who support them. EasyPath solves the critical problem of digital exclusion — where mainstream apps overwhelm users with complex interfaces, dense text, and unpredictable interactions — by providing a calm, forgiving, voice-enabled, and visually guided experience that adapts to each user's abilities. A dedicated caregiver dashboard enables trusted supporters to configure routines, monitor progress, and receive alerts without intruding on the user's autonomy.

## 2\. Essential Core Features

### 2.1 Simplified Interface System

* One task or piece of information displayed per screen at a time
* Large, clearly labeled buttons with icons and optional text labels
* Consistent layout and predictable navigation across all screens
* No hidden menus, dropdowns, or nested navigation layers
* Forgiving error handling with easy undo, no penalty messages, and calm prompts

### 2.2 Task Breakdown Engine

* Users or caregivers input a goal (e.g., "make tea," "fill out this form")
* AI (GPT-4o) decomposes the goal into numbered visual micro-steps
* Each step displayed one at a time with an icon, photo, and brief plain-language instruction
* Linear progress indicator showing current step vs. total steps
* "Back" and "Repeat" buttons on every step screen
* Steps can include photos uploaded by caregivers for personalization

### 2.3 Smart Reminder System

* Reminders for medications, meals, appointments, and daily routines
* Gentle audio chime and vibration notification
* Persistent soft re-prompts if a reminder is not acknowledged (configurable intervals)
* Missed-task escalation: alerts sent to a designated caregiver after a configurable number of missed acknowledgments
* Offline-capable reminder delivery using service workers

### 2.4 Visual Daily Schedule

* Timeline view with time slots, large icons, and optional photos instead of text
* Color-coded activity categories (meals, medicine, leisure, appointments)
* "What's next?" one-tap view showing the immediate upcoming task
* Caregiver-editable schedule synced in real time via Supabase

### 2.5 Text-to-Speech (TTS) and Speech-to-Text (STT)

* TTS: any on-screen text readable aloud with one tap of a persistent speaker button
* STT: microphone input for search, note entry, task creation, and navigation commands
* Adjustable speech rate and voice type in settings
* Voice-first mode: complete app navigation using only spoken commands

### 2.6 AI Text Simplifier

* Paste or type any complex text, or upload a photo of a document
* GPT-4o rewrites content in plain language (reading level adjustable: simple, very simple)
* Output read aloud automatically via TTS
* Saved simplified texts accessible in a personal library

### 2.7 Photo-Based Memory Aid

* "Who is this?" — user photographs a person; app retrieves saved name, relationship, and a note
* "What is this?" — user photographs an object; app identifies it and provides a plain-language description
* Caregiver or user can add/edit contacts with photo, name, relationship, and voice note
* Object library for everyday items (keys, medicine bottles, etc.)

### 2.8 AI "Explain This to Me" Button

* Persistent camera-access button on the home screen
* User points camera at a bill, sign, medicine label, or menu
* GPT-4o Vision analyzes the image and returns a plain-language spoken explanation
* Explanation displayed as large text and read aloud simultaneously

### 2.9 Safe Navigation (Landmark-Based Directions)

* User inputs a destination using voice or search
* Directions provided as step-by-step landmark descriptions ("Turn left at the blue shop")
* No complex map rendering; each step shown one at a time with a landmark photo where available
* One-tap "I'm Lost" button that sends the user's live GPS location to a trusted caregiver via Supabase real-time
* Arrival confirmation prompt

### 2.10 Emotion and Stress Check-Ins

* Scheduled or on-demand emoji-based mood logging (5-point scale with faces)
* Brief optional voice note attachment to mood entry
* If stress/negative mood detected, app suggests a calming activity from a personalized list
* Mood history visible to user and (with consent) to caregiver

### 2.11 Life-Skills Coach

* Guided simulations for real-world scenarios: using public transport, shopping, handling money, making a phone call
* Safe, gamified practice environment with no real consequences
* Step-by-step coaching with voice guidance and visual cues
* Completion rewards tied to the gamification system

### 2.12 Adaptive Interface Engine

* Detects repeated errors (3+ on same step) or long inactivity pauses (configurable threshold)
* Automatically simplifies the current screen (removes secondary elements, increases font size)
* Offers contextual help prompt: "Do you need help?" with options to retry, call a caregiver, or skip
* Adaptation events logged and visible in caregiver dashboard

### 2.13 Gamification System

* Points earned for completing tasks, check-ins, and life-skills modules
* Daily and weekly streaks with visual streak counters
* Reward badges displayed on a trophy shelf
* Celebratory animations that are non-flashing and calm (gentle confetti, friendly character)
* Progress never reset punitively; streaks "pause" rather than break

### 2.14 Personalization Settings

* Adjustable font size (small, medium, large, extra-large)
* High-contrast and color-blind-friendly themes
* Adjustable information density (minimal, standard)
* Speech speed control
* Language selection
* Caregiver PIN-lock for settings to prevent accidental changes

### 2.15 Caregiver Dashboard

* Separate login role with elevated permissions
* Create, edit, and delete tasks, reminders, and daily schedules for the linked user
* View task completion history, mood logs, adaptation events, and gamification progress
* Receive push notifications for missed reminders and "I'm Lost" triggers
* Shared notes area accessible to multiple caregivers, teachers, or therapists linked to one user account
* Manage linked user's contacts (memory aid) and life-skills modules

### 2.16 Offline Functionality

* Core features available offline via service worker caching: reminders, daily schedule, saved task steps, memory aid contacts
* Background sync for mood logs and task completions when connectivity is restored
* Clear offline indicator in the UI

### 2.17 Privacy and Consent Management

* Explicit consent flows for camera, microphone, and location access
* Data minimization: only necessary data collected
* User data deletion option in settings
* Caregiver access requires explicit user (or guardian) consent grant
* WCAG 2.1 AA + Cognitive Accessibility guidelines compliance throughout

## 3\. Tech Stack

### 3.1 Front-End

* **Framework:** React (with Vite as build tool)
* **Styling:** Tailwind CSS with a custom design token system for accessibility themes
* **PWA:** Vite PWA plugin (`vite-plugin-pwa`) with Workbox for service worker management, offline caching, and background sync
* **State Management:** Zustand for lightweight global state (user profile, preferences, offline queue)
* **Routing:** React Router v6
* **Animations:** Framer Motion (configured to respect `prefers-reduced-motion`)
* **Icons:** Lucide React + custom pictogram SVG set

### 3.2 Back-End

* **Platform:** Supabase
    * **Authentication:** Supabase Auth with email/password and magic link; role-based access (user, caregiver, admin)
    * **Database:** Supabase PostgreSQL — tables for users, profiles, tasks, schedules, reminders, mood logs, contacts, gamification, caregiver links, shared notes
    * **Storage:** Supabase Storage — for user profile photos, contact photos, task step images, and simplified document images
    * **Real-Time:** Supabase Realtime for live schedule updates, "I'm Lost" location push to caregiver, and shared notes sync
    * **Edge Functions:** Supabase Edge Functions (Deno) for server-side AI calls, reminder escalation logic, and location alert dispatch

### 3.3 AI Integration

* **Model:** OpenAI GPT-4o
    * Text simplification (text input → plain language output)
    * Task breakdown (goal input → micro-step list)
    * "Explain This to Me" (image + prompt → spoken plain-language explanation)
    * Photo-based object identification (image → description)
    * All AI calls routed through Supabase Edge Functions to protect API keys
* **TTS:** Web Speech API (browser-native) with fallback to OpenAI TTS API for higher-quality voice
* **STT:** Web Speech API (browser-native SpeechRecognition)

### 3.4 APIs & Integrations

| Service | Purpose |
| ------- | ------- |
| OpenAI GPT-4o API | Text simplification, task decomposition, image explanation, object ID |
| OpenAI TTS API | High-quality fallback text-to-speech |
| Web Speech API | Browser-native TTS and STT |
| Geolocation API | User location for safe navigation and "I'm Lost" feature |
| Nominatim / OpenStreetMap | Geocoding and landmark-based direction generation (open-source, privacy-safe) |
| Supabase Push Notifications | Caregiver alerts for missed reminders and location share |
| Web Push API | PWA push notifications via service worker |
| Camera API (MediaDevices) | Photo memory aid and "Explain This to Me" feature |

### 3.5 Technical Requirements

* PWA manifest with home screen install prompt, splash screen, and app icons at all required sizes
* Service worker implementing cache-first strategy for static assets, network-first for API data, and background sync queue for offline mutations
* HTTPS required for all PWA, camera, microphone, and geolocation features
* `prefers-reduced-motion` media query respected globally
* `prefers-color-scheme` respected with manual override in settings
* ARIA roles, live regions, and focus management implemented throughout
* All interactive elements meet WCAG 2.1 AA minimum touch target size (44×44px minimum)

## 4\. Design Preferences

### 4.1 Interface

EasyPath uses a warm, calm, and uncluttered visual language — large touch targets, generous white space, and friendly rounded shapes that communicate safety and ease. Every screen feels open and unhurried, with a consistent structure that eliminates cognitive load from navigation itself.

### 4.2 Color Palette

| Role | Color | Hex |
| ---- | ----- | --- |
| Primary | Soft Sky Blue | `#4A90D9` |
| Primary Dark (accessibility) | Deep Ocean Blue | `#2C5F8A` |
| Secondary | Warm Sage Green | `#6BB F8A` → `#68B28A` |
| Accent | Sunny Amber | `#F5A623` |
| Background | Off-White Cream | `#FAF8F5` |
| Surface | White | `#FFFFFF` |
| Error / Alert | Soft Coral | `#E8695A` |
| Success | Calm Green | `#4CAF7D` |
| Text Primary | Charcoal | `#2D2D2D` |
| Text Secondary | Medium Gray | `#6B6B6B` |
| High Contrast Mode | Pure Black on White | `#000000` / `#FFFFFF` |

### 4.3 Typography

* **Headings:** `Nunito` (Google Fonts) — rounded, friendly, highly legible at large sizes
* **Body / Labels:** `Atkinson Hyperlegible` (Google Fonts) — specifically designed for low-vision and cognitive accessibility, optimized for letter differentiation
* **Minimum body font size:** 18px (user-adjustable up to 32px)
* **Line height:** 1.6 minimum
* **Letter spacing:** 0.02em on body text

### 4.4 Additional Design Considerations

* **One-task-per-screen principle:** no scrolling required on primary task screens
* **Button design:** pill-shaped or large rounded rectangles, minimum 60px height, with icon + label always together
* **Icons:** simple, universally recognizable pictograms with text labels — icons never used alone as the sole meaning carrier
* **No time pressure UI:** no countdown timers visible to the user, no auto-advancing slides
* **Error states:** warm, non-alarming colors (soft coral, never harsh red); friendly copy ("Oops, let's try again!" never "Error 404")
* **Loading states:** gentle pulsing skeleton screens, never spinning loaders
* **Transitions:** slow, smooth fade transitions (300ms); all animations honor `prefers-reduced-motion`
* **Caregiver dashboard:** shares the same design language but uses a slightly denser information layout appropriate for a support professional context, distinguishable by a teal accent stripe

### 6.7 Navigation Principles

## 7\. User Flow

### 7.1 New User Onboarding Flow

1. User opens the EasyPath PWA URL on their device; the browser prompts "Add to Home Screen" (PWA install prompt)
2. App loads to the **Welcome / Splash Screen** (`/`); TTS automatically reads "Welcome to EasyPath. Here to help you every day."
3. User taps **"Get Started"** → navigates to **Role Selection** (`/onboarding/role`)
4. User taps **"I am the main user"** → navigates to **Profile Setup** (`/onboarding/profile`)
5. User adds a photo (or skips), enters their name via keyboard or microphone, and taps **"Next"**
6. User arrives at **Accessibility Preferences** (`/onboarding/accessibility`): selects large font, high contrast theme, slow speech speed; taps **"Next"** — settings saved to Supabase
7. User arrives at **Caregiver Link** (`/onboarding/caregiver-link`): enters caregiver's email and taps **"Send Invite"**; confirmation shown; taps **"Done — Go to My Home"**
8. User arrives at **Home Dashboard** (`/home`); TTS reads greeting; app shows "No tasks yet — let's add one!" empty state card

***

### 7.2 Daily Routine Flow (Returning User)

1. User opens app from home screen icon; Supabase Auth session auto-restores; lands on **Home Dashboard**
2. TTS reads: "Good morning, Alex! You have 4 things today. Next up: Take your morning medicine at 8:00 AM."
3. User taps the **"What's Next"** card → navigates to **Task Step View** Step 1: "Open your medicine cabinet. Tap Done when you're ready."
4. User taps **"Done — Next Step"**; Step 2 loads: "Take 1 blue tablet with water." TTS reads instruction automatically
5. User completes all 4 steps; **Task Complete Screen** loads; gentle star animation plays; "10 points earned!" badge shown; TTS reads "You did it, Alex! Great job."
6. User taps **"Back to Home"**; streak counter on Home increments
7. User taps **Schedule** in bottom nav → **Daily Schedule View**; sees color-coded timeline for the day
8. User taps the 10:00 AM "Doctor Appointment" event → Task Step View for pre-configured appointment steps

***

### 7.3 "Explain This to Me" Feature Flow

1. User receives a letter in the mail and cannot understand it
2. User opens app → taps the floating amber **"Explain This"** camera button
3. **Camera Helper** screen opens in "Explain This" mode; user points camera at the letter
4. User taps the large shutter button; photo captured and sent to Supabase Edge Function → GPT-4o Vision
5. Loading screen: "Figuring this out for you…" (gentle pulse animation)
6. Result card appears with simplified text in large font; TTS automatically reads the explanation aloud: "This letter is from your bank. It says your account is fine. No action needed."
7. User taps **"Save"** to add to Saved Texts library or **"Share with Helper"** to send to caregiver via Supabase shared notes

***

### 7.4 Caregiver Setup and Monitoring Flow

1. Caregiver receives invite email, clicks link → arrives at **Role Selection** (`/onboarding/role`) with "I am a caregiver" pre-selected
2. Caregiver completes caregiver account setup (name, email, password)
3. Caregiver lands on **Caregiver Dashboard** (`/caregiver/dashboard`); linked user's summary is shown
4. Caregiver navigates to **Schedule Manager** via bottom nav → adds tomorrow's routine: 8 AM Medicine, 9 AM Breakfast, 2 PM Physiotherapy; uploads a photo for the physiotherapy step showing the clinic entrance
5. Caregiver navigates to **Task Manager** → creates task "Pack gym bag" → taps "Break it into steps for me" → AI generates 5 steps → caregiver adds photos for each step → saves
6. Caregiver navigates to **Alert Settings** → sets "Notify me if medicine reminder is missed twice" and enables mood alerts for Stressed/Sad moods
7. Next morning: user misses medicine reminder; after second miss, Supabase Edge Function sends push notification to caregiver: "Alex hasn't acknowledged the 8 AM medicine reminder."
8. Caregiver opens app → sees alert in Dashboard alert feed → taps to send a message to user via Shared Notes: "Hi Alex, don't forget your medicine! It's in the cabinet."
9. User sees shared note as a notification card on Home Dashboard; TTS reads it aloud

***

### 7.5 "I'm Lost" Safety Flow

1. User is traveling to physiotherapy using **Safe Navigation** (`/navigation`)
2. User inputs "Physiotherapy Clinic" via voice → step-by-step landmark directions generated
3. User proceeds through 3 steps successfully, confirming each one
4. At step 4, user becomes confused and taps the large **"I'm Lost"** red button
5. App captures GPS location via Geolocation API; sends location coordinates and timestamp to caregiver via Supabase Realtime
6. User is taken to **"I'm Lost" Confirmation Screen** (`/navigation/lost`); TTS reads: "It's okay. Your helper has been told where you are."
7. Caregiver receives push notification: "Alex pressed I'm Lost. Location: [address]. Tap to view map."
8. User taps **"Call [Caregiver Name]"** → device native phone dialer opens
9. After situation resolved, user taps **"I'm Okay Now — Go Back"** → returns to navigation step 4

***

### 7.6 Mood Check-In and Calming Flow

1. App sends a gentle push notification at 3 PM: "How are you feeling? Tap to check in."
2. User taps notification → **Mood Check-In Screen** (`/mood`)
3. User taps the "Stressed" emoji face
4. **Calming Activity Suggestion Modal** appears: "Let's take a moment. Try one of these:"
5. User taps "Breathing Exercise" → a full-screen breathing guide loads: a slow expanding/contracting circle with text "Breathe in… Breathe out…" and calming audio
6. After 2-minute exercise, "Well done! That took courage." message shown with 5 points earned
7. Mood log saved to Supabase; caregiver is notified via push: "Alex logged a stressed mood at 3:04 PM and completed a calming activity."

***

### 7.7 Text Simplifier Flow

1. User navigates to **Simplify** tab in bottom nav → **Text Simplifier** (`/simplify`)
2. User taps microphone and dictates the text they want simplified, or taps "Take a Photo of Text" and photographs a document
3. User selects "Very Simple" reading level and taps "Simplify It"
4. GPT-4o processes text via Supabase Edge Function; result appears in large font; TTS auto-reads
5. User taps "Save" → text saved to **Saved Texts Library** (`/simplify/saved`) with auto-generated title
6. Later, user opens Saved Texts, taps the saved entry, and TTS re-reads the simplified content

***

### 7.8 Life-Skills Coach Flow

1. User navigates to Life Skills via Home shortcut grid → **Module List** (`/life-skills`)
2. User taps "Shopping at a Store" module card → **Module Screen** (`/life-skills/shopping`)
3. TTS reads scenario: "Let's practice buying bread at the shop. I'll guide you through each step."
4. User proceeds through simulated steps: picking up a basket, finding the bread aisle (landmark-style visual), choosing a loaf, going to the checkout
5. At checkout step, a decision point appears: "The cashier asks 'Do you have a loyalty card?' What do you do?" — 2 large option buttons: "Say No thank you" / "Say Yes and give my card"
6. User selects "Say No thank you" → "Perfect! That's exactly right." feedback + 15 points
7. User completes module → **Module complete** celebration screen → "Shopping Badge" awarded; visible on Trophy Shelf in Rewards screen
